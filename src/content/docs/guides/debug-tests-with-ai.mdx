## Goal

- Pause inside one Playwright test
- Inspect the current page state
- Run JavaScript in the test scope
- Collect evidence and identify a fix

## Before you start

- Install and configure the [Endform MCP server](/docs/reference/mcp-server)
- Authenticate with Endform
- Confirm the Playwright test runs with Endform
- Open the Playwright project in the MCP client workspace

## Select one test

- Filter by test file
- Filter by full test title
- Exclude matching tests
- Filter by Playwright project
- Select a test declaration with `file.spec.ts:LINE`
- Select a checkpoint source line
- Select a Playwright configuration file or test directory

## Start the debug session

- Call `debug_test_start`
- Wait for remote startup
- Record the `sessionId`
- Review the checkpoint file and line
- Review the initial ARIA snapshot

## Check session status

- Call `debug_test_status`
- Handle `starting`
- Continue from `paused`
- Wait during `running`
- Handle `ended`
- Clean up `stale`

## Inspect the test

- Read the inline ARIA snapshot
- Query the page with Playwright locators
- Inspect URL, text, roles, and attributes
- Capture browser state with screenshots
- Read stdout, stderr, and exit codes

## Iterate at the checkpoint

- Call `debug_test_run`
- Access fixtures such as `page`
- Use multiple JavaScript statements
- Use `await`
- Recover from code that throws
- Compare fresh ARIA snapshots
- Review new and changed artifacts

## Finish the session

- Record the evidence needed for a test or application fix
- Call `debug_test_stop`
- Confirm local and remote cleanup
- Account for the 15-minute session limit

## Troubleshooting

- More than one test matched
- No tests matched
- Session startup timed out
- Session ended before the checkpoint
- Session became stale
- JavaScript returned a non-zero exit code
- Expected artifacts were not returned
