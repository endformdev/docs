## Goal

- Identify historical test patterns
- Narrow trends to concrete executions
- Inspect errors and attempts
- Retrieve detailed trace data

## Before you start

- Install and configure the [Endform MCP server](/docs/reference/mcp-server)
- Authenticate with Endform
- Identify an organization with `list_organizations`
- Define the repository, suite, branch, project, or test to investigate

## Choose a dataset

- Use `suite-runs` for whole-suite behavior
- Use `test-runs` for individual tests and attempts

## Start with analytics

- Call `query_analytics`
- Choose `count`
- Choose `pass-rate`
- Choose `average-duration`
- Select a period and optional end timestamp
- Group by outcome
- Group by branch
- Group test runs by test
- Group test runs by project

## Narrow the analysis

- Add a `where` expression
- Filter by repository and suite directory
- Filter by branch and commit
- Filter by outcome
- Filter by duration
- Filter by test name and location
- Filter by project
- Filter by retry count
- Filter by attempt error

## Inspect matching executions

- Call `query_samples`
- Review suite-run samples
- Review test-run samples
- Compare ordered test attempts
- Inspect error messages and locations
- Review duration, outcome, branch, commit, and project metadata
- Follow `nextCursor` pagination

## Inspect trace data

- Find an attempt with `otelTraceId`
- Call `get_otel_trace`
- Relate trace data to the failing attempt
- Compare trace evidence with errors and timing

## Investigation workflows

- Find recurring failures
- Find flaky tests that pass after retries
- Find slow tests
- Compare branches
- Locate the first affected commit
- Compare Playwright projects
- Investigate repeated error messages
- Inspect a specific suite run

## Example prompts

- Summarize suite pass-rate changes
- Find the most frequently failing tests
- Find tests with increasing duration
- Compare failures between branches
- Inspect recent retries for one test
- Retrieve the trace for a failed attempt
