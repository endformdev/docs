The Endform Netlify extension runs your Playwright end-to-end tests against every Netlify Deploy Preview, without a separate CI workflow.

It:

- runs your suite with Endform as soon as a Deploy Preview is published
- shows the run and a link to the report in the Netlify deploy log
- reports the result as an **Endform** check on the GitHub pull request

Try it with our [demo repository](https://github.com/endformdev/playwright-tutorial), which deploys to Netlify as is.
