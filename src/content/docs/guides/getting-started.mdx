The easiest way to get started with Endform is to run the [Endform CLI](https://www.npmjs.com/package/endform) from your Playwright project directory.

```sh
npx endform@latest test
```

Deploying on Netlify? The [Netlify integration](/docs/guides/netlify-integration) runs your tests against every Deploy Preview, without a CI workflow.
